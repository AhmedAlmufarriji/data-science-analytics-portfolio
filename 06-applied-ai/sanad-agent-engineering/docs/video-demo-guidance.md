# Video demonstration — assessment context

For a real voice-agent demonstration, configure the prompt in the assessment's agent testing environment or another supported voice-agent platform, rather than playing back the scripted offline HTML.

## Recommended walkthrough

1. Introduce the solution and its neutral Saudi Arabic persona in English.
2. Ask an ordinary accident-reporting question in Arabic.
3. Test an emergency with an injury or vehicle smoke.
4. Request an insurance claim status without a connected lookup and evaluate whether the agent avoids invented data.
5. Explain the knowledge-base boundary, emergency workflow, tool outcomes, privacy and human escalation.
6. Conclude with the service value and the production integrations still required.

**Recording note:** Microphone audio and the agent's system/tab audio are independent channels. Verify both in a short local recording before producing the final walkthrough.

The recording created for the assessment had an AI playback capture issue; therefore this repository does not claim an acoustically verified production voice demo.
