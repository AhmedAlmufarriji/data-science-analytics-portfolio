# Dataset provenance and public repository policy

This portfolio includes **educational examples only**, not real customer deliverables.

- The restaurant Tips dataset is a public teaching example and is included for reproducible Python exercises. [Seaborn dataset repository](https://github.com/mwaskom/seaborn-data).
- The medical insurance dataset is sourced from an educational Kaggle dataset and fetched when running the code. The dataset is **not redistributed here**; consult its licensing terms before external commercial use.
- **No raw customer-level sales tables** from the supplied AdventureWorks or retail course ZIP files are published here. Recreate Power BI reports only using source data that you are authorized to access and share.
- Demo names and emails used in SQL/MongoDB exercises are synthetic course examples, not actual account credentials.
- No API tokens, authentication cookies, passwords, personal contact exports, or external service credentials should be committed.
- Visual prototypes in HTML are separate from native Power BI `.pbix` files.
- For public employment portfolios, remove sensitive source paths, personal identifiers, internal client names, and nonredistributable datasets before every commit.
