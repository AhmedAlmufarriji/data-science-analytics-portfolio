# Project Support

This repository is a personal, educational portfolio rather than a hosted support service.

## Where to begin

- Start with the [portfolio README](README.md) and select your area of interest.
- Open the README inside the relevant project for prerequisites and run instructions.
- For the standalone SANAD prototype, see [SANAD demo instructions](06-applied-ai/sanad-agent-engineering/README.md).
- For the forecasting notebook, use the [dedicated capstone repository](https://github.com/AhmedAlmufarriji/time-series-forecasting-capstone).

## Ask a question or report a problem

Use [GitHub Issues](https://github.com/AhmedAlmufarriji/data-science-analytics-portfolio/issues/new/choose) for reproducible bugs, broken links, or documentation problems.

Include the project path, your environment, the relevant command or interaction, and sanitized error output. Please don't post credentials or real personal/company data.

## Security issues

Follow the [Security Policy](SECURITY.md). **Never publicly post an exploit or secret.**

## Scope

Responses and fixes are provided on a best-effort basis; no guaranteed response time or production support is offered. Third-party websites, packages, voice services and datasets are outside the repository maintainer's control.
