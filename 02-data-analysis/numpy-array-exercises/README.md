# NumPy Multidimensional Arrays

A compact collection of array-creation, inspection, manipulation and indexing exercises.

**Stack:** Python, NumPy

## Exercises

`linspace`, `ndarray`, 3D-to-4D reshaping, converting data types, iteration with `nditer`, `where`, element indexing, concatenation and splitting.

This is a foundational programming exercise. It does not build a statistical model.

## How to get started

```bash
python -m pip install -r requirements.txt
python src/numpy_project.py
```

The script prints each intermediate array and its properties.
