# Community Code of Conduct

## Our standard

This repository is a professional and educational space. Contributions, questions and feedback should remain constructive, respectful, and focused on improving the work.

Examples of expected behavior:

- Offer specific technical feedback, especially when reporting an error.
- Respect differing experience levels and backgrounds.
- Credit collaborators, course materials, original sources and prior work.
- Protect private data and respect contributors' intellectual property.

Unacceptable behavior includes harassment, discriminatory remarks, personal attacks, intimidation, publishing someone else's private information, and repeatedly derailing technical discussions.

## Scope

This policy applies to repository issues, pull requests, discussions and other project-related participation.

## Enforcement

The repository maintainer may edit, hide, or remove abusive contributions and may restrict participation when necessary. Enforcement is based on the behavior and its impact, not on disagreement about technical choices.

For serious abuse, use GitHub's built-in reporting mechanisms. Avoid disclosing sensitive personal details publicly. If a private contact method is published on the maintainer's GitHub profile, you can request that channel for confidential discussion.

This is a community conduct statement for an individual portfolio; it does not represent an external organization or employer.
