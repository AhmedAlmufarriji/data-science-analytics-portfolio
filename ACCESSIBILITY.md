# Accessibility Statement

This is a personal educational portfolio containing Markdown documentation, Jupyter notebooks, Python examples and browser-based demonstrations.

I aim to make the projects **navigable, readable and understandable**, including for people who use keyboard navigation or assistive technologies.

## Current approach

- GitHub Markdown uses structured headings, lists, tables and descriptive links.
- Demos are intended to use readable contrast, visible keyboard focus, meaningful controls and language-appropriate text.
- The SANAD prototype has a right-to-left Arabic interface; real speech recognition and synthesis still depend on browser and device capabilities.
- Where possible, technical outputs are explained in written documentation rather than being presented only as visual charts.

## Known limitations

**No independent accessibility audit or WCAG conformance certification has been performed.** The portfolio includes third-party platforms and older educational visualizations which may have incomplete keyboard, screen-reader, speech or caption support. Dynamic dashboards and generated audio should not be assumed accessible without testing.

## Reporting a barrier

Open a [documentation issue](https://github.com/AhmedAlmufarriji/data-science-analytics-portfolio/issues/new/choose) and include:

1. The affected page, notebook, or demo.
2. What you were trying to accomplish.
3. The barrier you encountered.
4. Browser, device or assistive technology if comfortable sharing.

Please don't include private health details or other sensitive personal information in public issues.

I welcome focused suggestions for improving accessible documentation and interfaces.
